# Native beta design

The first visit should feel personal and calm: three concise introductions, then a name, then a role. The name is local personalization. Role selection opens a shared testnet persona; real company permissions come from invitations/assigned membership.

Follow the phone's system appearance. Warm off-white in light mode, near-black in dark mode, restrained clay accents, upright light Geist display type. Keep readable text sharp; use blurred material, soft light and fine edge highlights on decorative artwork. Give each screen one primary action and generous breathing room. No automatic slide advance. Decorative drift pauses when backgrounded and is removed under Reduce Motion; transitions use a short fade and 12-point movement otherwise.

Forms remain scrollable above a keyboard-aware pinned action. Back preserves the typed name and selected role. Name and role validation happen before connecting. A valid session and matching local profile are required before opening the app. Sign-out clears both. All money remains test money; live Earn is disabled.

Browser checks cover light390×844 and dark375×667, system appearance changes, name/role order, reduced motion, restore/logout, core test workflows and mainnet rejection. Real iPhone keyboard, VoiceOver and native secure storage behavior require device confirmation.
